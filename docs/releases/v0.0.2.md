# Brownie Water Tracker v0.0.2

Brownie is more personal, more flexible, and much easier to update.

## What's new

- Choose a daily hydration goal from 1,000 ml to 6,000 ml with a smooth drag control.
- Added Milkshake and Cold Drink to Customize Drinks, including effective-hydration calculations.
- Onboarding now keeps content clear of the camera and system edges, shows Brownie reliably, supports multiple hydration goals, and has a steadier target slider.
- Your selected goals now appear beneath the character on the Today dashboard.
- Added a user profile form for name, body details, health context, medication notes, and appointment notes.
- GitHub APK builds can check official Brownie releases, download an update, and open Android's installer.
- Added guided help for Samsung Auto Blocker and Android's install-from-this-source permission.

## Install note

Android always asks you to confirm an APK installation. On Samsung, Auto Blocker may need to be temporarily disabled under **Settings > Security and privacy > Auto Blocker**. Brownie will show guidance if installation is blocked.

## Distribution note

The self-update flow is included only in the GitHub APK build. The Google Play build excludes the package-install permission and uses Play's update system.
